# Microservices-Based E-Commerce Application

A cloud-native e-commerce application built using
microservices architecture.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Docker
- Kubernetes
- GitHub Actions

## Microservices

1. Product Service
2. User Service
3. Order Service

## Project Goal

To develop an independently deployable,
scalable e-commerce application using
microservices architecture.
